# Option A — Sliding-Pin Release

Option A is the Phase 0 release architecture. Retention comes from the magnet's axial pull — gate 5, retention ≥ 1.8 N. Release is a single Ø2.0 mm sliding pin with 3.0 mm travel whose only job is breaking contact; there are no cams on the Phase 0 face.

- Pin bore: Ø2.05 (+0.05), located at (+6.65, +3.50) on the 20 mm face.
- Pin engagement: 3.00 mm design, ≥ 2.5 mm acceptance. The 1.0 mm plate consumes 1.0 mm, so the mating receptacle must be at least 2.5 mm deep to land the pin with margin.
- First-article actuation: manual — finger or flat tool on the pin tip.
- Solenoid or retraction-actuator drive is deferred to Phase 1 / later cells.
- This architecture applies to both the 20 mm Phase 0 cell and the 25 mm cell. The 25 mm cell's axial pin is a hard-lock, separate from the release function.
- Cams (the old Ø16.05 dual-cam design) are retired from Phase 0 and documented as superseded in `docs/GATE5_SUPERSEDED.md`.
