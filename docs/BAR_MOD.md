# BAR-MOD — Barrier Module

Design owner: Craig.  
Date: 2026-11-27.  
Status: **paper only**. Depends on the locked Phase 0 20 mm face article and measured shear/cycle data. Does not change baseline geometry or Phase 0 locks.

Rapid-assembly physical barrier or shielding panel. Forms walls, L-corners, or temporary pathways using the same docking face and hold already specified.

## Form factor & interface
- Envelope: same 4–8 cm³, shell slightly thicker for panel stowage.
- Docking face: identical to the locked Phase 0 20 mm article.
- Hold and release: identical Ø6.0 × 2–3 mm Nd disc + coil (release-only).
- Mass budget: ≤ 50 g.

## Payload
- Deployable panel: thin polymer or foil sheet stored rolled or folded.
- Deployment: spring or small gas charge (paper) that unrolls and locks into adjacent BAR-MODs via the existing pin/EPM hybrid.
- Deployed size (paper): ~15 cm × 15 cm per module.

## Mechanical
- Face-to-face docking forms a continuous plane.
- Shear and cycle numbers come straight from the Phase 0 40 N / 2 000-cycle tests.
- Once locked, zero power required to maintain the barrier.

## Lattice behavior
- Swarm docks into a row or grid → panels deploy → rigid wall.
- Gaps for gates by simply not docking those faces.
- After use, panels can be restowed (paper design assumes manual restow for Phase 0).

## Failure modes
- Panel snag → module still functions as structural node.
- Incomplete dock → shear capacity drops to the measured T3 number; swarm detects via existing cycle-count logic.

## Dependencies
- Same as EX-MOD: Phase 0 face article + real shear/cycle data from the measurement card.

Paper until measured. Credit follows data. See PHASE0.md and MODES.md.
