# DittoBot Community Enhancement Suites — Matching Features

Design owned by Craig. Started Nov/Dec 2025. Programmable matter.

All features below are **optional and zero-impact** on locked Phase 0 criteria, 25 mm option A geometry, process locks in `LOCKS.md`, force targets, or measurement cards. They do not mint V2.0. Two stacks stay unmixed. Credit follows measured data when it arrives.

These are the suites that match the current lattice work and the post-2040 scale-change modes (inward compaction, outward expansion, hierarchical nesting, variable-density zones, split/merge). Grouped by the earliest phase where they become useful.

---

## Near-term optional (bench / early lattice)

Useful on a single face or small coupon. Do not change locked tests.

- Soft safety skin (mandatory only on human-proximate builds)
- EPM / contact BIST
- Self-healing coating
- Dust / contamination tolerance
- Field-replaceable contact pad inserts
- Standardized visual fiducial / alignment markers
- Simple impact / shock event detection
- Condensation / surface moisture detection
- Low-power local uptime / event chronometer
- Production test-point / bed-of-nails pads

---

## Mid-term lattice support (small assemblies)

Enables reliable multi-node docking, power, and health while cells stay the locked size.

- Expanded local energy buffer
- Short-range inter-node power sharing
- Swarm recovery / brownout consensus support
- On-node precision timing / sync
- Peer load / force sensing between docked faces
- Face-to-face thermal contact quality sense
- Local thermal runaway isolation
- Lattice majority-vote hardware support
- Lattice-level simple load balancing hooks
- Peer magnetic state cross-check
- Soft-dock approach guidance lighting / acoustic ranging
- Edge-side anomaly / health detection hooks
- Node health score aggregation hooks
- Standardized external sensor / expansion bus
- Modular face specialization

---

## Post-2040 enablers (scale-change modes)

Directly support the five scale-change modes in `POST_2040_OUTLOOK.md`. Still optional. Still zero-impact on locked baselines.

**Inward compaction / outward expansion**
- Expanded local energy buffer + short-range power sharing (energy during motion)
- On-node precision timing / sync (coordinated release and re-lock)
- Peer load / force sensing (confirm seating during density change)
- Soft-dock guidance + fiducials (reliable approach in dense packing)
- Swarm recovery / brownout consensus (survive partial power loss mid-sequence)

**Hierarchical nesting**
- Modular face specialization
- Modular internal payload / sensor bay
- Standardized external sensor / expansion bus
- Peer optical intensity / link quality calibration
- Optical mesh wavelength diversity / secondary IR

**Variable-density zones**
- Lattice-level load balancing hooks
- Peer load / force sensing
- Local temperature gradient mapping
- Soft safety skin + 35 N interrupt (sparse outer surfaces)
- Health score aggregation

**Split / merge swarm scaling**
- Swarm recovery / brownout consensus
- On-node precision timing / sync
- Low-power RF discovery beacon
- Acoustic soft-dock ranging / proximity assist
- Lattice majority-vote hardware support
- Formal contributor credit / attribution hooks (modules keep identity across merges)

**Shared across modes**
- Water / immersion sealing package (if any mode is used outdoors or in fluid)
- Corrosion / salt-fog protection
- Localized electrostatic dust / particle repulsion
- Micro-heater / de-icing assist
- Vibration damping / isolation pads
- Fail-soft optical aperture covers
- Standardized debug / test edge connector

---

## Explicit non-goals

- No suite changes Phase 0 ON ≥ 3 N, OFF < 0.3 N, 40 N shear, 1.25 A soak, or cycle targets.
- No suite changes 25 mm option A pocket, magnet stack, AWG 36, DRV8871, or retired 28.8 N.
- No suite is required for a measured latch or a filled `MEASUREMENT_CARD.md`.
- Soft safety skin remains mandatory only on human-proximate builds; optional on bench coupons.

Near-term work is unchanged: wind, pulse, pull, and publish numbers on the locked faces.
