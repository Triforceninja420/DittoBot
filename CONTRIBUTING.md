# Contributing to DittoBot

Thanks for your interest in making programmable matter real!

## Ground rules

- Paper until measured. Simulations set the bar; they don't earn credit. Credit follows the measurement card.
- Design owned by Craig. Changes to locked values require discussion.
- Keep docs in sync with CAD, BOM, firmware, and sims.
- Funky fresh commits preferred: clear messages, no noise.

## How to contribute

1. Fork or branch.
2. Make your changes (docs, sims, CAD, firmware).
3. Run tests: `pytest` (Phase 0 math tests).
4. Open a PR with a clear description of what and why.
5. If you build hardware, fill [docs/MEASUREMENT_CARD.md](docs/MEASUREMENT_CARD.md).

## Areas that need help

- Physical Phase 0 first article: machining, assembly, measurement.
- Lab screening for Mars bacteria swarm oxidative/cold data.
- Control app (see docs/CONTROL_APP.md).
- Community enhancement suites.

Open an issue to discuss first if the change is big.

Funky fresh and measured beats speculative every time.
